# 🏪 まちかどマート — コンビニ経営シミュレーション

ドット絵の街でコンビニを経営しながら、発注・廃棄・機会損失・需要予測などの経営を体で覚えるブラウザゲームです。PCとスマホ（縦画面）の両方で遊べます。

**遊ぶ** → https://y-0323.github.io/conveni-management-sim/

> 現在は **M1＋α（試作版）**：3カテゴリ（おにぎり・弁当／飲料／ホットスナック）、店内の様子（棚の商品が減る・レジ・お客さんの動き）、毎日の発注と緊急補充、日報、軌道に乗ったら空き物件に出店（最大4店舗）。
> 全体の計画は [docs/design.md](docs/design.md) を参照。

## 遊び方

- 時間が流れ（1倍速で1日 約2分半）、お客さんが棚から商品を取り、レジで会計します。右上で一時停止・3倍速・10倍速
- **店内／街**：地図左上で切り替え。商品が減ると棚が空いていき、「残りわずか」「品切れ」の札と警告が出ます
- **発注**：明日の朝6:00に届く数を決める（店舗タブの各商品からも変更可）。天気予報・曜日・過去の売れ方がヒント
- **🚚 緊急補充**：営業中に追加発注すると2時間後に届く。1回¥2,000の配送料がかかり、22時で受付終了
- **日報**：毎朝6:00に全店の結果と講評が届く。廃棄（余った原価）と売り逃し（取り損ねた粗利）を見比べよう
- **🏗 出店**：7日以上営業し、直近7日の営業利益が15万円以上で、出店費用を払える現金があれば、空き物件に出店できる。物件ごとに客層（会社員・学生・住民）が違う
- 街はドラッグで移動、ピンチ／ホイールで拡大。お店をタップすると店内へ、空き物件をタップすると出店画面へ

## 開発

```bash
npm install
npm run dev      # http://localhost:5173/conveni-management-sim/
npm test         # シミュレーションの数値テスト
npm run build    # 本番ビルド（dist/）
```

`main` に push すると GitHub Actions がテスト → ビルド → GitHub Pages へ公開します。

## 構成

| ディレクトリ | 役割 |
|---|---|
| `src/sim/` | シミュレーション（時計・需要・在庫・会計・推奨発注・講評）。描画に依存しない純粋なTypeScript |
| `src/data/` | 商品カテゴリ・客層・物件・街マップ・店内レイアウトの定義 |
| `src/game/` | Phaser 3 による店内と街の描画（ドット絵はコードで生成） |
| `src/ui/` | Preact による経営画面（HUD・発注・店舗・日報） |
| `src/core/` | 実時間とシミュレーションをつなぐ進行役、セーブ |
| `tests/` | Vitest によるテスト |

技術：TypeScript / Phaser 3 / Preact / Vite / Vitest

数値は学習用に簡略化したモデルです。
